# Red Dead Redemption II — Vintage Character Slider

A western / antique-paper restyle of the supplied JavaScript image slider. Built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP.
2. Open `slider.html` in Chrome, Edge or Firefox. No build tools or installation are needed.
3. Internet access is required for the Google Fonts and the default artwork wallpaper. Replace the `artwork` URL in `js/slider.js` with a local image path if you want it fully offline.

## Included
- Vintage sepia palette, distressed grain overlay, western typography and wanted-poster framing.
- Six character slides, previous/next controls, autoplay, hover/focus pause, progress bar and responsive layout.
- Original Font Awesome local CSS and webfonts from the supplied project.

## Add your own character artwork
Put your images in `assets/` and set each slide's `image` value in `js/slider.js`, for example `image: './assets/arthur.jpg'`. The current starter uses one RDR2 ensemble wallpaper URL for all six character entries; use individual licensed character images for distinct portraits.

Artwork and game names belong to their respective rights holders. This is an unofficial fan-made frontend project.
